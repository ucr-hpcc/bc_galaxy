## [0.0.2] - 2026-28-05
### Added
- Added `install-galaxy-part1.sh` to install Galaxy 25.0.3
- Added `install-galaxy-part2-p1.sh` and `install-galaxy-part2-p2.sh` to configure preset tools
- Added configuration and tool files to interact with environment module system
- Added custom webhook to masthead panel to allow users to change slurm job settings for jobs submitted via Galaxy through slurm
- Added configuration and tool files to interact with environment module system

### Fixed
- Get Data from external data sources has been resolved
- Remote user authentication. Achieved by modifying source `remouteuser.py` file

### Changed
- Galaxy config files are generated by `before.sh.yml` instead
- Update README
- Job Configuration. Currently, the jobs submitted via Galaxy will either run on the same node as the Galaxy instance(local) or via slurm(cluster)
